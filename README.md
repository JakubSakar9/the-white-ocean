# The White Ocean

An atmospheric audio-based video game.

## How to run

The game was created in Godot 4.3. In order to build, clone the repository to a folder and open it as a Godot project. The game uses the Forward+ rendering method, so not all platforms will work properly.
Unlike previous versions, this version uses some C# scripts, so only mono version of Godot will work for the project.

If you wish to play the game without building it, visit the [itch.io page](https://jetsy.itch.io/the-white-ocean).
